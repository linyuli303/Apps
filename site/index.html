Shared changes: use Request addition/removal via GitHub. Review the prefilled form, confirm the operation and channel ID, check the confirmation box, and submit while signed in as linyuli303. Only owner-opened requests are eligible. Changes appear on all devices only after successful processing, refresh and deployment. Reload this page afterward.

Local changes: Add locally and Remove locally change this browser's draft only. Removing locally hides videos immediately; adding locally does not fetch videos. Published channels hidden locally remain listed here so you can restore them or request removal. Export remains available for advanced bulk editing.

Requests, channel IDs and the repository are public. Do not include credentials. No API keys or GitHub tokens are accepted here. Anyone using this browser can edit its local draft; this is not parental access control.

GitHub requests open in a new tab and do not submit automatically. Channel names are search labels, not approval identifiers. Resolve handles and review their immutable channel IDs before adding.
